kith-people — the people you invited, and the app invites that bring them in.

  kith people [ls] [--json]                  everyone invited (not you, not a bot): id, name, access removed or not, the
                                             agents they have and as what, and their bots. Read from kith-auth, the one
                                             place that says who a person is.
  kith people show <id> [--json]             one person in full
  kith invite add <name> --agent A[=member|guest] ... [--person ID] [--json]
                                             invite someone to the app: prints the link to send them. --agent is repeated,
                                             one per agent, the role after = (default guest, the narrower one). With
                                             --person ID the invite is for someone kith already knows (name optional).
                                             The running host makes the invite (kith serve); nothing is done without it.
  kith invite ls [--json]                    the invites this computer made (never a token or hash)
  kith invite revoke <inviteId> [--json]     take one back before it is used (already gone: changed false)

Not this: `kith auth invite <id>` makes a one-time /link code for a chat channel. A bot's invite: `kith bot invite`.
Exit: 0 done, 1 refused / host unreachable / not found, 2 usage. --json: one object {"ok": true, ...} on stdout, or
{"ok": false, "error": "..."} with the same exit codes.
