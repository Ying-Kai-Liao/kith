A home for the agents you build.

Kith turns your Claude Code, Codex or pi setup into agents with their own skills, memory and accounts. Each one is a folder on your Mac. Talk to them in one app, call them from any repo, share one with a link.

What's in the folder.

The role folder holds the agent's instructions, skills and tools. It is a git repo you can share. Beside it sit the agent's memory, data and files, which stay with you.

Put a role on GitHub and others install their own copy. Their agent starts with your skills and none of your memory.

The agent format

agents/reading

role/agent.md · shareable
--- name: reading description: tracks what I read model: sonnet effort: medium harness: claude --- You keep track of what I read. Save each article with one line on why it matters. On Fridays, list what I finished.
# or for one run kith ask reading -H claude "what did I finish?"
# start from one someone shared on GitHub kith install owner/repo # list its versions; kith restore brings one back kith history reading

Every version is kept

The role is a git repo. When the agent learns a skill, that is a change you can read and roll back.

It carries no accounts

An agent says which services it needs. You grant one of your accounts, and the key reaches only the process that uses it.

Your choice of engine

One line in agent.md sets it: harness: codex. The -H flag changes it for one run.

One job each

Each agent loads only its own skills and tools. Adding a tenth doesn't weigh on the other nine.

Send someone your agent.

It keeps working on your Mac. They open your link in a browser, sign in and start talking, with nothing to install. A link is for one person and works for 24 hours.

You choose guest or member. A guest asks you before anything that needs permission. A member works within the limits you set. Set a monthly spending limit for each person, and remove them whenever you like.

They can bring a bot of their own, such as Grok, as a guest. You decide whether it joins. Answer the card here to see how.

Goes with the link

  • An invite to the agents you choose
  • The work it does for them
  • Their own bot can join, as a guest

Stays on your Mac

  • The agent's files
  • Its memory, and each person's chats
  • Your accounts and keys

For people you invite, the agent runs on Claude Code, on your own plan. What they ask counts toward the monthly limit you set. It answers only while your Mac is on.

The rest is built in.

  • Chat channels

    Message an agent on Telegram, Slack or Discord.

  • Routines on a schedule

    Run an agent at a set time. Read the result when you're back.

  • Roll back any version

    kith history lists every version. kith restore brings one back.

  • Roles and limits

    Guest or member, and a monthly limit, for each person you invite.

  • Cost per agent

    Every run is logged with its agent. kith cost agents compares them by day, week or month.

  • Memory per person

    Each person you invite gets their own memory. They can't read yours.

  • Your other Macs

    Ask an agent on another Mac of yours over ssh. Only the task, your code and its answer travel.

  • Open source

    Apache-2.0. An agent is plain files in a git repo.

Questions

Something else? Ask on GitHub.

What do I need?

A Mac, Apple silicon or Intel, with at least one of Claude Code, Codex or pi installed and signed in. Kith is an app and the kith command. The app's engine picker lists Claude Code and Codex. You set pi in agent.md. Sharing with other people needs Claude Code.

What does it cost?

Kith is free and open source, under Apache-2.0. Each agent runs on your own plan with the provider of its engine. Runs for people you invite use Claude Code, so they count toward your Claude plan, up to the limit you set.

What does the person I invite need?

A browser. They open your link, sign in, and talk to the agent there.

What if my Mac is off?

The agents don't answer until it is back on. People you invited see that your computer is offline. Their chats are kept on your Mac and show again when it's on.

What leaves my Mac?

Chats with people you invite pass through the Kith cloud, encrypted end to end. The cloud can't read them. If a device is offline they wait there for up to 24 hours, still encrypted. The cloud keeps your account, your devices and who can reach which agent. Your prompts go to the provider of the engine the agent runs on, under your own account. Files, memory and keys stay on your Mac.

Usage analytics are on by default. They say which features you use, never your messages, code or files. Switch them off in Settings > Privacy. The full list is on the privacy page.

Does it run on Linux or Windows?

No, agents run on macOS only. There is a Linux app, which is a client: it reaches a Mac that runs them.

Start with one agent.

Download Kith and make one agent for a job you do every week. When it's good, send it to someone.
