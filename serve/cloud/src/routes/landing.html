How sharing works

Three steps, and the agent never leaves your computer.

  1. videoon your MacBook · ready
    designeron your MacBook · asleep

    Build it on your Mac

    An agent is a folder with its instructions, skills and tools. Start one with kith new.

  2. Invite to videoCopy link
    Rexcan use video

    Send the link

    Make an invite link for one agent and send it however you usually talk to them.

  3. Rex wants to use video
    AllowDenyAlways allow

    They use it, you approve

    Each new person or bot asks first. You choose Allow, Deny or Always allow.

Made an agent worth sharing?

Each Kith agent is a folder and a git repo, in an open format. Share it from your Mac by link, or put it on GitHub so others can install their own copy.
